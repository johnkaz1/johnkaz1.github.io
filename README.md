# 🚀 John Kaz — Cyberpunk Developer Portfolio

Welcome to my personal interactive portfolio website hosted on GitHub Pages!

🌐 **Live Demo:** [https://johnkaz1.github.io](https://johnkaz1.github.io)

---

## ✨ Features

- **Interactive Neon Canvas**: Dynamic particle mesh reacting to cursor movements.
- **Cyber Terminal**: Full CLI experience (`help`, `skills`, `projects`, `matrix`, `sudo`, `clear`).
- **Tech Explorer**: Categorized stack showcasing Web Development, AI/ML, and DevOps.
- **Projects Showcase**: Interactive showcase with category filtering & quick-view modals.
- **Synthesizer SFX**: Custom sci-fi audio effects generated dynamically via Web Audio API.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Styling**: Custom CSS Variables, Glassmorphism & Neon Design System
- **APIs**: Web Audio API, HTML5 Canvas API
- **Deployment**: GitHub Pages & GitHub Actions
